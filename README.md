# AppHub Studio v1.1

Painel dark de atalhos para os aplicativos de `elementacional`.

## Correção dos links

Cada projeto com página HTML simples agora possui **Abrir app** (endereço potencial do GitHub Pages) e **Código** (repositório). Os projetos que exigem backend/build ou não têm `index.html` permanecem como repositório. **A existência de `index.html` não confirma publicação:** habilite GitHub Pages em cada repositório antes de usar os links web.

O aplicativo migra os atalhos-padrão da v1.0 no armazenamento local sem apagar personalizações.

## Publicar o painel

Coloque `index.html` na raiz de um novo repositório e habilite **Settings → Pages → Deploy from a branch → main → / (root)**.

## Personalização

Adicione novos links, altere nome/descrição, envie ícones SVG simples e reorganize os cartões arrastando. Exporte/importa a configuração JSON para usar em outros navegadores; mudanças locais não atualizam o GitHub automaticamente.
